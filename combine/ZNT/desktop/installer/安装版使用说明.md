# 路安智巡 · SmartRoad-Inspection 1.4.6 道路实验室版

本版包含道路检测流程、道路风险分类与提示词、证据核验、问题报告、人工复核和道路法规检索。软件处于实验室小试阶段，模型输出为待复核线索；演示数据和合成图测试不代表真实高速场景准确率。

## 安装与启动

1. 安装版：双击 `SmartRoad-Inspection_Setup_v1.4.6_x64.exe`，按向导安装，然后从开始菜单打开“路安智巡 SmartRoad-Inspection”。
2. 便携版：完整解压 ZIP 到可写目录，双击根目录 `SmartRoad-Inspection.exe` 或 `start-platform.bat`。不能只取出 EXE 运行。
3. 默认进入演示模式，不自动启动大模型。实验室初始账号为 `admin`，密码为 `admin123`。

运行系统为 Windows 10/11 64 位。基础软件含 Python、已编译前端和业务后台，浏览界面无需 Node 或 GPU。安装版还包含微软签名的 WebView2 离线运行环境，已有该组件时跳过安装。建议预留至少 3 GB 基础安装空间，模型空间另计。同一台电脑请避免同时启动安装版和便携版。

## 本次界面与展示更新

- 首页新增可旋转的乐西高速三维示意模型，联动设备点位和路况报告。路线、桩号、设备与事件均标记为虚构演示。
- 深蓝工业主题与黑白水墨明亮主题可切换；黄红警示保留，照片及检测证据保持原色。
- 双击首页摄像头名称进入对应监控画面；随包包含 5 张正常道路参考图，按设备 ID 匹配，不代表真实现场视频。
- 系统设置和右下角可调整 100%–200% 字号，自动保存。
- 点击“放大查看”后滚轮缩放，或 Ctrl＋滚轮整体放大至 400%；左键拖动平移，Esc 恢复操作，不挤压布局。
- 图文操作说明见 `docs/HIGHWAY_OVERVIEW.md`、`docs/INK_LIGHT_THEME.md` 和 `docs/READING_AND_ZOOM.md`。

## 历史归档与道路检测能力

- 历史档案支持原图缩略图、场景标注、各风险掩码及逐图报告；正常场景也可完整保存。检测任务中心的“归档留存”将已完成记录排除出缓存自动清理。
- 支持导入专用检测档案 ZIP，逐文件校验、重复导入去重；保留原检测时间、图像和模型结论，历史导入不触发现场告警、工单或模型训练。15 图开发测试档案另行提供，不混入新用户的业务数据库。
- 在“检测任务中心 → 只看已归档 → 过程与结果”查看；迁移时可用“导入检测档案”，格式与操作见 `docs/DETECTION_HISTORY.md`。升级已有道路安装版会保留已经归档的图片与证据。

以下道路 v5 能力与检测记录沿用上一版，本次更新没有重复运行真实模型或形成新检测成绩。

- 接入 v5 道路概念检测流程：区分普通湿路与可见水体淹没，支持同图多种风险及多个目标实例；将已观察实体编译为 SAM3 短概念提示词。
- 未见可见异常的场景显示绿色道路框，可见路牌作为蓝色场景对象单独标注；路牌存在本身不构成设施损坏。
- 限制视觉复核输入长度，修复多实例导致的上下文溢出；按风险 ID 绑定证据图，报告包含原图、场景标注及实际预测掩码。
- 已完成 10 张高速合成场景与 5 张 UA-DETRAC 正常候选图的真实 Qwen/SAM3 开发回归，15 张流程均完成。部分水体边界、碎片与背景同类目标仍需人工核查，该小样本结果不代表检测准确率。

- 登录页使用道路品牌标识，部署页引导上传图片进行明确标注的演示联调，不再宣传旧工地预置案例。

- 修复自动问题报告链接缺少桌面检测网关前缀导致的 404；支持默认网关和用户指定的检测服务地址。

- 默认运行道路演示、道路离线或道路云端档位，旧工地流程不作为道路检测入口。
- 使用道路风险算子、视觉核验和报告流程；道路实时初筛模型暂未训练，默认关闭旧 YOLO 初筛。
- 附带《中华人民共和国道路交通安全法》2021 年修正文本的道路巡检相关条款及官方来源记录，首次启动写入道路知识库。条款用于辅助分析，不自动作违法认定。
- 独立保存道路事件、报告、复核记录、阈值及知识库；安装包不携带开发者的事件数据库、模型路径、测试输出或已导入私人资料。
- 移除交付目录中的旧工地演示图片、报告素材和构建缓存。

## 配置真实检测

在“模型与规则”页面打开模型部署引导，准备检测 Python 环境、Qwen 和 SAM3 组件，再选择本机路径、运行环境检查并启动服务。模型权重、GPU 依赖、llama.cpp 和 SAM3 仓库不随本基础安装包提供。已有模型可以继续使用，在新安装目录中重新选择已有环境与模型路径即可。

默认随包 Python 只承担界面和基础服务；真实检测请选择已安装相应依赖的检测环境。模型部署细节参见 `requirements/DEPLOYMENT_GUIDE.md` 和软件内引导。以一张道路图片完成真实检测并检查证据、问题报告和待复核状态后，再扩展测试范围。

## 升级、迁移与卸载

- 从旧工地 SiteSafe 版本迁移：本版使用独立产品目录和注册标识。请新装到独立目录，不覆盖旧工地程序，也不要将旧工地业务备份直接作为道路业务恢复。
- 已有道路安装版：先备份，再正常关闭软件和后台服务，在原安装目录运行新安装包。程序管理的道路流程 YAML 模板随版本更新；个人模型设置、阈值覆盖、通知配置和业务资料保留。
- 已有道路便携版：新建目录完整解压，再使用道路版的工作空间备份/恢复迁移；确认模型和 Python 路径在新位置有效。
- 卸载：在 Windows“已安装的应用”或开始菜单选择卸载。卸载移除程序与快捷方式，保留 `desktop-settings.json`、个人配置、`road_app_data/`、`road_knowledge_base/`、`outputs/`、`runtime/`、自备模型和环境。卸载后目录可能非空。
- 保留的 `sitesafe-install.ini` 是兼容命名的本产品识别标记，勿复制到无关资料目录。共享 WebView2 不随软件卸载。

安装器不会强制关闭其他模型进程。默认配置、业务资料以及原有模型应先备份；本机安装测试不能替代所有新设备、驱动和权限环境的验收。
