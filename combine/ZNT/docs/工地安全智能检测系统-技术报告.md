# 工地安全智能检测系统技术报告

## 1. 系统总览

系统面向施工现场安全管理，完成「图像 → 风险识别 → 人工/自动处置 → 复盘」全链路：

```text
工地摄像头 / 无人机 / 安全员手机
        ▼
[A] 视觉感知与 Token 压缩
        ▼
[B] MLLM驱动的开放风险识别（含证据门控）
        ▼
[C] 风险推理智能体（等级 + 规范 + 处置建议）
        ▼
[D] 协同处置智能体（确认 + 工单 + 通知）
        ▼
[E] 复盘学习智能体（案例库 + 阈值建议 + 交底）
        ▼
[F] 管理平台前端（PC 后台 / 大屏 / 移动端）
```

**已实现并可验证**（见 `docs/AGENT_REGISTRY.md` 与评测记录）：

- 50 图公开数据集评测：**0 误报 / 精确率 100%**，verified 召回 24%、含人工复核召回 44%  
- 29 项单元测试通过  
- 支持单图离线检测、批量检测、RTSP/视频抽帧实时检测  
- 支持 Web 演示与正式后端（角色鉴权、WebSocket 推送）

---

## 2. 输入侧：多源图像接入

系统接受三类现场图像来源：

| 来源 | 接入方式 | 数据模式 |
|------|----------|----------|
| 工地固定摄像头 | `run_stream_inspection.py` 按间隔抽帧，或桥接服务截帧 | `realtime` |
| 无人机航拍 | 批量图片输入 | `offline` |
| 安全员手机 | 前端上传（平台「实时检测」页） | `offline` / 移动上报 |

统一由 `DetectionEvent` 契约承载（设备、时间、媒体、几何、风险、处置字段），
离线/实时用 `data_mode` 区分，便于前端一致渲染。

## 3. 视觉感知与 Token 压缩

`[A]` 对应感知模块（非 Agent 决策）：

- **全图发现**：第一遍多模态大模型（MLLM，当前配置 Qwen 视觉）理解施工场景并逐项评估候选风险。  
- **背景/小目标压缩**：API 模型无法暴露内部视觉 Token，系统采用「全图发现 → 实体定位 → 局部裁剪 → 复核」的两阶段路径；`pipeline.person_precheck` 开启时，先由 SAM3 预检人员并逐人放大裁剪，随全景图一起送第一遍，缓解中远景小目标（如未戴安全帽）漏检。  
- **风险区域裁剪**：`crop_*.jpg` 保留风险关系所需上下文（人员、吊物及其间区域），供第二遍证据复核使用。

## 4. MLLM驱动的开放风险识别模型

`[B]` 为检测核心，对应流水线编排器与证据门控：

### 4.1 视觉主干网络
以预训练 MLLM 作为视觉-语义主干，不进行梯度训练；企业落地可把云端 MLLM 适配器换成本地部署模型，保持相同 JSON 协议。

### 4.2 MLLM 施工语义理解
第一遍输出结构化 `FirstPassResponse`：场景摘要、每项候选风险 `present/absent/uncertain`、可见事实、不确定信息，并自动拆解出风险主体、危险源、防护物与区域，生成 SAM3 短文本提示与空间关系检查任务。

### 4.3 多尺度语义投影器（无训练证据链）
最终系统采用**MLLM结构化风险描述与无训练证据链**完成开放风险识别：

```text
全图 MLLM 语义
+ SAM3 实体与分数
+ 几何关系核验
+ 局部裁剪复核
+ 可选 CLIP 语义一致性
→ 最终视觉结论
```

其中 CLIP（ViT-L/14）只做语义一致性辅助，**不直接决定**风险置信度。

### 4.4 SAM2 风险区域定位（本实现为 SAM3 桥接）
- 文本驱动的实体分割输出 Mask / Box / Score；  
- 风险区域由掩码构造策略生成：`entity_union / subject_only / object_only / intersection / projected_below / missing_subject / expanded_object_zone`；  
- 缺失型风险（防护栏、安全带、安全帽等）采用分级协议：`confirmed_absent ≤ 0.90`、`not_observed ≤ 0.60`、`occluded ≤ 0.35`，避免把「未检出」直接当「缺失」。  

> 报告沿用你框架中的「SAM2」表述；工程实现对应 `integrations/sam3_bridge_user.py`（本地权重 `sam3.pt`）。

### 4.5 证据门控与二次核验
- 关系核验：`below_and_horizontal_overlap / near / inside / overlap / blocks_region / missing`；  
- 第二遍 MLLM 基于原图 + 叠加图 + 裁剪图 + 分数 + 关系结果，产出 `visual_verification.json`，锁定最终视觉事实。  
- 门控行为：关键实体未定位 → 降置信或撤销；关系核验失败 → 不直接确认关系型风险；遮挡/模糊 → 保留不确定性。

## 5. 风险推理智能体

`[C]` `RiskReasoningAgent`（确定性规则，便于向评委与安全员解释）：

- **风险等级判断**：基础严重度（critical/major/general）× verified × 置信度降级规则；未 verified 但需复核 → `pending_review`，未 verified 且无需复核 → `info`（仅存档不告警）。  
- **施工规范知识库**：`examples/regulations.json` 内置 JGJ 59/80/46/130、GB 6067、GB 50720 等 20 条规范条款与处置动作库；另支持 `knowledge_base/` 任意规程文件（.md/.txt/.pdf/.docx）条款级入库检索。  
- **处置建议**：按 `risk_id` 附带现场处置建议，供协同处置层引用。  
- **边界**：不得修改视觉结论。

---

## 6. 误报与不确定性分析

系统在设计上优先抑制误报：

- 候选发现与证据确认**分离**：MLLM 可发现疑似风险，但自动确认必须同时满足「实体定位 + 语义一致性 + 空间关系 + 二次核验 + 硬证据门控」。  
- 缺失型保守策略：默认 `allow_missing_from_non_detection=false`，SAM3 未检出防护物**不能**直接作为缺失证据；`not_observed` 强制转人工并限制置信度上限。  
- 评测佐证（`outputs/eval_v1/eval_scores.json`）：50 张（正 25/负 25）**误报 0、精确率 1.00**；`confirmed_absent` 6 例全为真阳性。  
- 已知短板如实记录：第一遍感知对**中远景小目标**召回不足（漏报主因），已通过 `person_precheck` 两阶段感知显著缓解；门控不建议放松（会牺牲当前 100% 精确率）。

## 7. 协同处置智能体

`[D]` `CollaborativeResponseAgent`：

- **自动建单**：verified 风险按 SLA 生成工单（critical 2h / major 24h / general 72h），附处置建议；`pending_review` 生成安全员确认请求。  
- **状态机**：`pending_confirmation → confirmed → assigned → rectifying → rectified → closed`，含 `rejected_false_alarm` 终态；非法迁移被拒绝。  
- **通知责任岗位**：经通知网关分发（file 审计底账始终开启；配置 `SAFETY_WEBHOOK_URL` 可启用企业微信机器人；失败不阻塞主流程）。  
- **整改跟踪**：工单流转与关闭构成整改闭环，结果回写事件与案例库。

---

## 8. 复盘学习智能体

`[E]` `ReviewLearningAgent`：

- **接收人工确认结果**：安全员确认/驳回回流 `case_library.jsonl`，含模型结论、人工裁决、复核人与备注。  
- **更新现场规则和阈值**：按 `risk_id` 统计误报率并生成阈值调整建议；实现「提案 → 人工审批 → `configs/threshold_overrides.json` → 门控即刻生效」闭环（不自动改视觉结论）。  
- **风险案例库**：沉淀可用于培训与检索的案例。  
- **生成班前教育材料**：按确认案例生成 `briefing.md`，供班前安全交底使用。

## 9. 前端展示与操作流程

前端为三端一体（本仓库已实现并预留接口）：

| 端 | 作用 | 关键页 |
|----|------|--------|
| PC 管理后台 | 日常运营与处置 | 首页驾驶舱、实时视频监控、**实时检测**、工单处置、复盘分析、检测结果汇总、模型规则配置、案例库、资源管理 |
| 门口可视化大屏 | 出入口警示播报 | 高危滚动、今日隐患/整改率、案例循环、班组排名 |
| 安全员移动端（H5） | 现场确认与上报 | 工单提醒、告警弹窗、整改闭环、案例查询、人工上报 |

### 操作流程（线下图片 → 平台结果）

1. 双击根目录 `start-platform.bat（已内置）`（检测桥接，端口 8810；默认 Mock 可联调）。  
2. 双击 `start-platform.bat`，登录（管理员/安全员/总监，密码任意）。  
3. 进入「实时检测」：  
   - **上传图片**：选择现场照片 → 开始检测；  
   - **摄像头截帧**：打开摄像头 → 截帧并检测。  
4. 右侧实时展示各阶段协同：接收图像 → 视觉初检 → SAM3 掩码 → 证据核验 → 二次确认 → 风险推理 → 处置建议。  
5. 检测完成后查看风险结论、标注叠加图与处置建议；可跳转「风险工单处置」闭环整改，或「检测结果汇总」查看批次成果。  
6. 真实模型：`python detect_bridge.py --config configs/qwen_visual.yaml --port 8810`（需本地权重与 API Key）。

前端对接统一走 `api/` 与 `ai/` 分层，替换 Mock 为真实服务时无需改动页面。

## 11. 后续优化方向（基于实测）

1. 继续提升第一遍小目标感知召回（更高输入分辨率/分块提问策略）；  
2. 风险目录补充「人员—安全带—可靠挂点」等关系型条目；  
3. 缺失型风险推广多视角采集，降低单视角误判；  
4. 阈值调整继续走「提案-审批-生效」人工闭环，避免自动放宽。
