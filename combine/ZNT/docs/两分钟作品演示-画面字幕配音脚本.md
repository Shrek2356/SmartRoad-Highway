# SiteSafe Sentinel 两分钟作品演示录屏脚本

## 一、成片目标

- **目标时长**：116.5 秒，必须控制在 120 秒以内。
- **核心叙事**：实时初筛 → 开放风险识别 → SAM3定位 → 证据与规范核验 → 工单处置 → Agent复盘。
- **推荐示例**：全片尽量使用同一条“人员位于悬吊物下方”案例，保证检测结果、Mask、报告和工单前后连贯。
- **字幕与配音**：下表“字幕/AI配音稿”逐字一致，后期直接用字幕生成AI配音。
- **可信展示**：真实离线推理等待可压缩，但必须显示“推理过程已加速 ×8”；预置案例保持界面原有“演示素材”标识。

## 二、录制前准备

1. 分辨率设为 `1920×1080`，30 FPS；浏览器缩放100%，系统缩放100%或125%。
2. 使用暗色主题，隐藏书签栏、下载栏、开发者工具和无关标签页。
3. 关闭通知、聊天软件和可能出现个人信息的程序。
4. 提前完成一次目标案例检测，确保“检测结果汇总”和“风险工单处置”中已有对应记录。
5. 提前在RAG知识库导入一份规范，准备检索问题：`吊装作业时，人员为什么不能位于悬吊物下方？`
6. 模型配置页不要展示API Key；涉及绝对路径时只录状态卡或将路径区域裁掉。
7. 推理阶段完整录制，后期只加速无状态变化部分；每次阶段切换至少保留0.7秒原速画面。
8. 建议分镜分别录制再剪辑，不要强求一次连续完成两分钟。

## 四、字幕视觉规范

- 字体：`思源黑体 Medium`、`HarmonyOS Sans SC Medium`或`微软雅黑`。
- 1080P字号：正文38～42 px；项目名或章节提示48～54 px。
- 字色：主体白色 `#FFFFFF`；技术关键词可用青色 `#5FE7FF`；风险/告警关键词可用橙色 `#FFB45C`。
- 背板：黑色半透明圆角底，透明度55%～65%；不要使用纯黑满宽色条。
- 位置：底部安全区向上80～100 px，避开页面按钮和浏览器状态栏。
- 行数：最多两行；优先在逗号、分号处换行，每行不超过24个汉字。
- 动效：字幕使用120 ms淡入、100 ms淡出，不逐字跳动，不使用花哨入场。
- 技术标识：“推理过程已加速 ×8”“演示素材”等说明放右上角，字号24～28 px，不与配音字幕混排。

## 五、AI配音建议

- 声线：自然、克制的普通话女声或中性科技声，不使用过度广告腔。
- 语速：`1.00～1.05×`；若成片超过118秒，优先缩短画面停顿，不要把语速提高到1.15×以上。
- 停顿：逗号约0.15秒，分号约0.25秒，句号约0.35秒。
- 情绪：开头稳重，中段技术说明清晰，结尾略微增强但不喊口号。
- 音量：配音作为主声道；背景音乐保持在配音下方约18～22 dB。
- 发音词典：`YOLO`读“优洛”或逐字母统一一种；`SAM3`读“S-A-M 三”；`RAG`读“R-A-G”；`Agent`统一读“智能体”或英文，不要混用。

## 六、录制与剪辑顺序

1. 先录“实时检测提交—推理阶段—最终结果”，这是最容易受模型状态影响的核心镜头。
2. 再录“结果汇总—工单—RAG—复盘”，确保使用同一条风险记录。
3. 然后录“实时视频监控—首页驾驶舱”。
4. 最后刷新登录页，录制候机动画和登录切换。
5. 按时间表剪成116.5秒，导入配套SRT，再由字幕生成AI配音。

## 七、成片验收清单

- [ ] 总时长不超过120秒，建议116～118秒。
- [ ] 画面中没有API Key、个人路径、通知、聊天窗口或浏览器隐私信息。
- [ ] 至少展示一次检测桥在线状态。
- [ ] 至少展示一次开放风险候选发现、SAM3叠加图和像素Mask。
- [ ] 至少展示一条RAG规范依据和一张风险工单。
- [ ] 三个Agent名称和职责均进入画面。
- [ ] 推理加速和演示素材均有明确标识，不造成真实时延或实时数据误解。
- [ ] 字幕与AI配音逐字一致，字幕不遮挡关键结果。
- [ ] 结尾回到系统全景并保留短暂停顿。
