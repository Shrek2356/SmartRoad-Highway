# 筑安智巡 · SiteSafe-Sentinel 安装版

## 安装与打开

1. 双击 `SiteSafe-Sentinel_Setup_v1.4.1_x64.exe`。
2. 阅读使用授权，选择安装目录；建议保留默认当前用户目录。
3. 选择是否创建桌面快捷方式，点击安装。
4. 从桌面或开始菜单打开“筑安智巡 SiteSafe-Sentinel”。首次默认进入演示模式，不自动启动大模型。

这是 Windows 软件安装包：会创建开始菜单、可选桌面快捷方式及“已安装的应用”卸载入口。没有添加账号注册或联网授权机制。现有便携包仍可独立使用，但同一台电脑不要同时启动两份软件。

Windows 10 / 11 x64；建议至少预留 3 GB 磁盘空间供安装临时文件和基础程序使用，模型需要另行预留更多空间。显示界面建议 1920×1080。包内已包含便携 Python、前端构建、基础后台、原有八张关键案例、掩码、报告与动画，不需要额外安装 Node 来浏览。

## 新电脑部署模型

软件内打开 **模型规则配置 → 模型部署引导**，按页面执行：

1. 选择演示、本地离线或云端检测目标，了解需要的组件。
2. 创建真实检测环境；演示环境不必重装。
3. 准备 YOLO 工地权重、SAM3；本地离线再准备 Qwen 模型、视觉投影与运行程序。CLIP 为可选项。
4. 在页面选择这台电脑的真实路径，运行环境检查。
5. 检查通过后启动相关服务，再用一张图片完成真实检测验收。

权重不随安装包提供，项目权重下载链接保持留空，后续由维护者补充。模型可以放在安装目录之外，不要求沿用开发电脑的盘符。具体配置见同目录 `README.md`、`requirements/DEPLOYMENT_GUIDE.md`，或开始菜单“模型部署助手”。

## 升级、迁移和卸载

- **升级**：先从软件内备份，正常关闭软件及后台，再运行新的安装包，使用同一目录；安装器不覆盖已有个人配置。
- **旧便携版迁移**：请新建安装目录，不要把安装程序直接覆盖到旧便携目录。通过已有备份/恢复功能转入数据，模型路径在新电脑重新检查。
- **卸载**：Windows 设置 → 应用 → 已安装的应用 → 筑安智巡 → 卸载；也可使用开始菜单卸载入口。
- **保留资料**：卸载不会主动删除 `runtime/`、后端 `app_data/`、`outputs/`、`knowledge_base/`、已有 `configs/`、`.env`、`desktop-settings.json`、自行安装的 `env/`、`models/` 或 `third_party/`。其中程序随包下发的默认配置与规范种子文件也保留。原目录可能不是空文件夹，这是有意的数据保护。
- **完整清理**：先确认备份有效、无其他软件共用模型，再自行清理保留的资料；安装器不提供自动清空所有数据的选项。
- **重新安装**：保留的 `sitesafe-install.ini` 用于识别本产品目录。重装到原位置可继续使用已有资料；不要把这个标记复制到其他资料目录。

WebView2 为共享窗口组件：存在时跳过，缺少时使用包内微软离线安装程序。卸载筑安智巡不会卸载共享 WebView2。

## 安全提示与边界

项目 EXE 与本安装包尚未配置发布者代码签名，Windows 可能显示“未知发布者”或信誉提醒。这不等于已经通过安全认证；请核对来源和 SHA-256，勿关闭系统防护。正式面向公众发布前应申请代码签名并做干净 Windows 设备验收。

安装器会阻止向已有其他资料的非本产品目录安装，并在升级/卸载前检查后台服务。不强制终止正在运行的模型；先关闭软件，必要时运行安装目录的 `stop-platform.bat`。

同版本重装与卸载保留测试不等于所有未来版本均可安全迁移。降级不受支持；升级始终先备份。本机验收也不能代替没有 WebView2、不同权限/驱动或组织策略的新电脑实测。
