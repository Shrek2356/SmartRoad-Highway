# 筑安智巡 · SiteSafe-Sentinel v1.4.0

本版完善桌面操作可靠性与工作空间维护，保留 v1.3 的明暗主题、嘉然动画、八个预置案例、检测框、掩码及报告。未调整检测策略，未增加大模型调用。

## 打开软件

完整桌面运行包解压后，双击根目录 `SiteSafe-Sentinel.exe`。源码本地构建的入口为 `desktop-dist/SiteSafe-Sentinel.exe`。不要只复制一个 EXE；它依赖应用目录中的前端、后台与便携 Python。

Windows 10/11 x64，需要 WebView2。演示使用随包基础环境；真实检测需按 `requirements/` 安装完整推理环境和另外准备权重。本版不会替用户下载大模型。

## 四项可靠性修复

1. **导出可确认**：PDF、工单 CSV、安全交底、海报和诊断摘要统一接入桌面保存窗口。写入完成才提示成功；取消不会生成文件；失败不截断旧文件。浏览器只能确认“已发起下载”，不会假报已保存。单次导出上限 64 MB。
2. **阈值保存稳定**：停止拖动后保存，保存中暂时禁用该滑块；失败恢复已保存值。后台串行处理配置更新并原子替换 JSON，避免并发修改覆盖和读到半写入文件。修改作用于新任务，不追溯改变历史判断。
3. **复盘数据不串项目**：仅当前请求可更新图表，离开页面使未完成请求失效。切换明暗主题只重绘已有数据，不重复查询。查询失败明确提示并暂停导出。
4. **环境检查可运行性**：启动和保存桌面设置前，实际执行目标 Python，检查 64 位、Python 3.10+ 和基础依赖，推荐 3.12；清除开发机 PYTHONPATH 干扰。检查有超时，不加载模型，也不等于 GPU 推理验收。配置不合格不覆盖原设置。

另外修正项目元信息更新的错误返回值、关于页的过时版本号；打包前检查 EXE 与前端源码版本、便携 Python 依赖，交付默认使用相对路径的基础 Python。

## 完整工作空间备份

入口：**系统设置 → 用户与工作空间备份 → 完整工作空间备份与恢复**。需要新版 EXE 与本机业务服务的管理员账号；浏览器不提供本机离线恢复控制。

1. 点击“选择位置并安排备份”，选择一个尚不存在的 ZIP 文件。
2. 等当前检测任务完成，正常关闭软件与其他使用此业务目录的后台。
3. 重新打开软件。系统在启动服务前制作并逐文件校验备份。
4. 返回该入口检查“工作空间备份已完成”、文件位置和时间。安排之后不重启，不会立即产生备份。

维护安排可在重启前取消。服务仍在运行、磁盘空间不足或目标已存在时，不会强关其他程序或覆盖旧备份。失败信息保留在同一页面。文件数上限 100,000、未压缩数据上限 10 GB；更大部署应采用独立存储备份方案。

### 覆盖范围

| 包含 | 不包含 |
|---|---|
| 业务数据库、用户与角色、工单和业务附件 | 大模型权重、推理环境、程序代码 |
| 本地规范文件和索引 | 云端 API Key 与 `.env` |
| 检测桥任务原图、掩码、结构化结果、报告 | 独立历史实验目录、后台日志、旧备份 |
| 用户阈值、通知对象、模型路径与开关配置 | 桌面 Python/端口配置、浏览器登录状态与界面偏好 |

只迁移平台管理目录内的资料。外部素材绝对路径、外部模型与摄像头网络地址不自动变成随包文件。包内自带的八个展示案例由应用运行包提供，不依赖用户备份。

备份含现场资料和业务账号信息，**不是匿名文件，也不是加密压缩包**；不要公开发布，只恢复本人信任的 SiteSafe 工作空间备份。

## 恢复与迁移

1. 在目标设备完整部署同版或兼容版本软件，先用 Demo 打开并以本机管理员登录。
2. 选择备份 ZIP，确认恢复范围。备份格式、路径、文件大小与 SHA256 均须通过校验。
3. 等任务结束，关闭并重新打开软件，启动服务前执行恢复。它会替换当前业务工作空间，不是合并两个数据库。
4. 恢复前自动生成 `runtime/desktop/workspace/recovery-*/before-restore.zip`；原目录也保留。任一步骤失败回滚；中途退出留下恢复日志时，下次启动先回滚，不对半恢复的数据启动服务。
5. 重新登录，核对规范、工单、任务图片与报告。恢复会带回备份中的业务账号；请确认掌握该备份的管理员密码。
6. 原工作目录内的结构化图片路径自动映射到新目录；外部模型路径保留，需重新选择。当前设备的桌面 Python/端口和云端密钥不被备份覆盖。
7. 恢复后暂停 Qwen 自动启动、摄像头自动运行及未完成任务的自动续跑。请确认模型与视频源配置，再手动启动或重试，避免恢复时自动推理或调用云服务。

失败时先查看维护结果；若提示另一个后台仍占用目录，关闭它后重新安排。若回滚本身受文件占用影响，软件会停止启动业务服务并保留恢复日志，请先关闭占用程序，再重开，不要删除 `runtime/desktop/workspace`。

## 验证边界

软件回归覆盖导出保存/取消/失败、目标 Python 缺依赖、阈值并发保存、复盘请求乱序与卸载，以及隔离工作空间的备份恢复、恶意路径/篡改拒绝、文件占用回滚和模拟进程中断恢复。

这些验证不等于重新测试模型准确率，也不意味着已完成长期生产压测。现有真实现场数据、模型权重和展示素材未参与恢复试验。
