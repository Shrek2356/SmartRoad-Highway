# 道路证据流程修正 v3

日期：2026-09-13。范围：道路实验室软件源码，不发布安装包，不推送远端。

## 本次实现

- 新增 road_evidence.py 道路证据汇总模块。在既有安全守卫之后按第一遍原始发现对账，保留低于定位阈值但有观察或不确定性的候选。不会提高分数，也不会因定位失败删除观察。
- 输出 evidence_state：观察状态、定位状态、定位质量验证状态、道路关系、道路影响、复核原因和确认来源。结构化报告、事件与检测API保留这些字段。
- 定位状态区分未尝试、失败、部分目标定位和已有预测；已有掩码不标为有效真值。道路关系未解决时道路影响保持未知。
- 道路复核使用独立提示构建器，实际道路流程不再拼接工地复核说明。修正图像输入标签中残留的 construction-site image。
- 首轮提示要求先描述事实、保留备选解释，定位文字对应具体物体，移除固定 debris 定位示例。每次运行保存 first_prompt.txt。
- 风险目录新增道路阻塞、泥沙颗粒物覆盖和一般道路状况异常；业务侧仍进入待复核。
- 复核提示按覆盖、缺口、阻塞和损伤分别检查，明确掩码错误不能否定原图发现。
- 检测页面展示观察说明、定位状态、道路影响和复核原因；“置信度”改为“模型分数”。

## 仍需后续验证的架构能力

本次未引入额外模型规划调用，首轮仍同时输出事实与定位任务，只是职责约束与输出核对更明确。独立定位规划Agent、自动区域重试、结构化全图质量分析与固定摄像头道路区域标定尚未实现。
