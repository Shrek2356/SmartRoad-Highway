# 筑安智巡 · SiteSafe-Sentinel 桌面版 1.1.0

本轮定位：完善桌面软件和业务链路，不重训模型、不增加视觉审核轮次。仍保留嘉然动画、八个关键案例、风险框、掩码和预编辑成果图。

## 已完成的工作

| 范围 | 修改与价值 |
|---|---|
| 桌面通信 | 内置同源网关支持 HTTP 各方法、表单上传、二进制图片、WebSocket；接口错误不再退回 HTML 页面。 |
| 真实登录 | 使用用户输入的账号密码；演示角色按钮仅显式填入示例账号，不覆盖新增用户的凭据。 |
| 生命周期 | 关闭时仅结束本窗口创建的进程树，共享服务不被接管或误停；启动中关闭可取消后续启动。 |
| 环境配置 | 桌面内可选择 Python、默认模式与三个端口；保存后下次启动生效。子服务连接随端口配置更新，本地请求绕过代理。 |
| 模型控制 | 新增 llama-server.exe 路径选择；保留 Qwen 启停、模型路径、云端连接和 CLIP 开关。 |
| 配置留存 | WebView 使用持久化配置目录；保留主题、接口设置等，但每次启动仍首先打开登录页。 |
| 历史任务 | 从持久化摘要读取历史，支持分页、状态筛选、排队取消、失败/取消后重新检测。取消不强杀运行中的模型。 |
| 异常恢复 | 中断任务恢复时重定位原图；队列溢出或图片缺失明确显示失败，不留下永远排队的任务。 |
| 真实进度 | 流水线在实际发现、定位、证据整理、视觉核验、报告节点回传进度；不再在推理结束后模拟逐阶段完成。 |
| 规范导入 | 暂存解析、原子替换、索引加锁；空白或损坏的新文档不覆盖已有规范。扫描件仍需要先 OCR。 |
| 图片与视频 | 迁移后的同名掩码不任意串到其他案例；支持 MP4/WebM 和 FLV，RTSP 与窗口预览分别配置。掩码按视频实际显示矩形对齐。 |
| 产品界面 | 新增任务中心、全局服务状态、专业工作台/展示视图、运行时展示素材开关；用户与备份集中到系统设置。 |
| 持续验证 | 增加前端回归、桌面网关回归及真实本地服务联调测试，并配置 GitHub Actions。 |

## 推荐操作路径

1. 解压整个桌面交付文件夹，双击根目录 `SiteSafe-Sentinel.exe`。
2. 默认演示模式。管理员 `admin / admin123`；安全员 `safety / safety123`；只读总监 `viewer / viewer123`。真实账号权限由后台决定，不是任意密码登录。
3. 首页状态栏确认业务后台、检测桥连接状态。离线“配置齐备”不代表模型已常驻显存。
4. 在“检测结果汇总”查看预置案例；“展示视图”保留完整队形象横幅，工作台压缩装饰区域。
5. “系统设置 → 工作台与展示”控制是否显示预置素材和演示运行记录；关闭不删除文件。
6. “系统设置 → 桌面与连接”配置完整 Python 环境；“模型规则配置”选择权重、推理引擎与云端接口。
7. “实时检测”提交图片或全图巡检；“检测任务中心”跟踪任务、查看结果或重试失败任务。
8. “Agent 协同学习”处理模型疑问、人工裁决和学习提案；提案须经管理员批准才改变规则。

## 验证范围与边界

2026-09-07 本地回归结果：**143 项 Python 测试通过、3 项前端逻辑测试通过，前端与 Windows EXE 构建成功**。其中包含使用真实 FastAPI 服务和桌面网关的 HTTP/WebSocket 联调，并非仅用接口桩返回成功。GitHub Actions 工作流已配置；云端运行结果应以仓库 Actions 页面为准。

软件回归覆盖：原有业务/Agent/规则测试，新增登录、规范替换保护、历史恢复、取消、媒体归属、桌面启动关闭和配置留存测试；真实本地 HTTP/WebSocket 服务经过桌面网关完成登录、规范上传、演示图片任务、图片回传与消息交互。

演示任务使用 Mock 适配器，且验证其不生成真实数据库事件。上述测试不代表重新获得了模型检测率、误报率或 GPU 吞吐指标；沿用历史模型结论，真实部署仍需在目标硬件验证。

## 迁移和备份

便携演示带 Python 与基础依赖、已构建前端，无需 Node、系统 Python 或大模型。Windows 需 WebView2；真实检测按 `requirements/DEPLOYMENT_GUIDE.md` 配置 GPU 环境及权重。

“立即备份业务库”只备份 SQLite。完整迁移应先关闭窗口，再一并复制：

- `detectmodel/Site_Safety_OpenRisk/app_data/`：业务库、用户、工单及业务附件。
- `detectmodel/Site_Safety_OpenRisk/outputs/`：任务原图、掩码、摘要及运行配置。
- `detectmodel/Site_Safety_OpenRisk/knowledge_base/`：导入规范。
- `detectmodel/Site_Safety_OpenRisk/configs/`：初始化配置、阈值和规则。
- `desktop-settings.json`：桌面环境配置。
- 如需保留窗口偏好，再复制 `runtime/desktop/webview-profile/`；该目录含用户会话信息，不用于公开分发。

新设备须更新外部模型与 Python 路径。交付包不携带开发机 API Key、登录会话、运行数据库、模型权重和调试日志；公开分发前仍应检查第三方素材与模型授权。

## 本轮未包含

代码签名证书、自动升级服务器、企业级 SSO、集群调度、数据库/图片/知识库的一键整体恢复、RTSP 自动转码服务，以及真实多摄像头长时间负载测试均未宣称完成。当前成果是可独立运行、可展示和可做部署试点的桌面版本，不等同于已完成无人值守生产认证。
