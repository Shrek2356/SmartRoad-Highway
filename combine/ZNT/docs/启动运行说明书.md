# 工地 AI 安全智能检测系统 · 启动运行说明书

> 面向前端外行：按步骤操作即可在本机跑起来（全部使用 Mock 数据，无需后端）。

---

## 一、系统包含什么？

本仓库是一套**三端前端框架**：

| 目录 | 端 | 技术栈 | 默认端口 |
|------|----|--------|----------|
| `pc-admin/` | PC 管理后台 | Vue3 + Ant Design Vue + Flv.js + ECharts | 5173 |
| `big-screen/` | 工地门口可视化大屏 | Vue3 + DataV + ECharts | 5174 |
| `mobile/` | 安全员移动端 | Vue3 + Vite（H5） | 5175 |

---

## 二、环境准备（只需做一次）

### 1. 安装 Node.js

1. 打开浏览器访问：https://nodejs.org/
2. 下载 **LTS 长期支持版**（建议 18 或 20）
3. 一路下一步安装
4. 打开 **命令提示符** 或 **PowerShell**，输入：

```bash
node -v
npm -v
```

能显示版本号即表示安装成功。

### 2. 安装代码编辑器（可选但推荐）

- 推荐安装 [Cursor](https://cursor.com/) 或 [VS Code](https://code.visualstudio.com/)
- 移动端与 PC / 大屏一样用 Node.js 即可（`cd mobile && npm run dev`）

---

## 三、启动 PC 管理后台（必做）

### 步骤

也可直接双击仓库根目录的 **`start-platform.bat`**（同时启动检测服务与 PC 后台），或 **`start-platform.bat`**。

> `（已删除，请用 start-platform.bat）` 只打开浏览器地址，**不会启动服务**。服务未开时点网址会打不开，见 `docs/打包分发说明.md`。

或手动：

1. 打开终端，进入项目目录：

```bash
cd k:\ZNT\pc-admin
```

2. 安装依赖（第一次需要，约 1～3 分钟）：

```bash
npm install
```

3. 启动开发服务器：

```bash
npm run dev
```

4. 浏览器自动打开，或手动访问：http://localhost:5173

### 登录账号（密码任意）

| 账号角色选择 | 说明 |
|--------------|------|
| 管理员 admin | 可看全部 7 个菜单 |
| 安全员 safety | 驾驶舱 / 监控 / 工单 / 案例库 |
| 总监 director | 除模型配置外大部分菜单 |

登录页可直接点角色单选，再点「进入系统」。

### 能看到的页面

1. 首页数字驾驶舱  
2. 实时视频监控  
3. **实时检测**（上传图片 / 摄像头截帧 → 算法流水线 → 结果展示）  
4. 风险工单处置  
5. 智能复盘分析  
6. 检测结果汇总  
7. 模型规则配置  
8. 安全案例库  
9. 基础资源管理  

> 使用「实时检测」前，请先双击根目录 **`start-platform.bat（已内置）`**（默认 Mock，无需 GPU）。未启动时页面仍可本地演示流程。

## 六、常见问题

### Q1：`npm` 不是内部或外部命令？

Node.js 未安装成功，或未重启终端。重新安装 Node.js 后**关掉终端再开**。

### Q2：端口被占用？

- PC 管理端改 `pc-admin/vite.config.js` 里的 `server.port`  
- 大屏改 `big-screen/vite.config.js` 里的 `server.port`

### Q3：视频画面为什么是占位？

当前为 Mock 模式，没有真实摄像头流。接入方法见《对接指南》中「视频流对接」章节。

### Q4：地图为什么是 CAD 示意图？

已预留高德 / 百度接入位，见 `pc-admin/src/components/SiteMap/index.vue`。

### Q5：如何停止服务？

在对应终端按 `Ctrl + C`。

## 七、建议体验路径（5 分钟）

1. 用**管理员**登录 PC 后台  
2. 看首页驾驶舱指标与点位图，点底部「演示 AI 检测链路」  
3. 进入「实时视频监控」，切换 4/9/16 分栏，看红橙黄掩码  
4. 打开「风险工单」，点详情处置、再点批量导出  
5. 打开「检测结果汇总」，浏览 7 个样例的三联图与置信度结论  
6. 另开大屏页全屏展示  
7. `cd mobile && npm run dev`，体验告警弹窗与工单推进
