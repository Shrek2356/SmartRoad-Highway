# 筑安智巡 · SiteSafe-Sentinel v1.4.1

## 首次打开

完整解压桌面包，双击根目录 `SiteSafe-Sentinel.exe`。不能只复制 EXE；程序、前端和便携 Python 依赖完整目录，但不要求原电脑盘符。演示不需要另外安装 Python、Node 或大模型。Windows 10/11 x64 需要 WebView2 Runtime。

八个预置案例、嘉然动画、检测框、掩码与报告仍保留；本次不调整风险检测算法，不运行新的模型效果评测。

## 新电脑接入模型

打开 **模型与规则 → 新设备部署**，选择演示、本地离线或云端视觉，依次完成：

1. 准备环境：新建官方 SAM3 环境使用 Python 3.12 x64，独立安装匹配的 CUDA PyTorch 与完整依赖，不污染随包 Demo 环境。
2. 取得组件：查看所选模式的模型来源和推荐放置目录；Qwen GGUF 与 mmproj 必须配套，llama.cpp 保留 DLL，SAM3 还需安装代码。
3. 配置路径：选择检测 Python，保存后重启；自动查找模型、手动浏览补齐，再保存初始化配置。
4. 检查与启动：点击环境检查，按实际检测 Python 的缺项提示处理；手动启动 Qwen 或配置云端 API。YOLO/SAM3 按任务加载。
5. 图片验收：先提交一张新图片，再做八图真实回归。预置案例不等于当前电脑推理结果。

完整说明位于 `requirements/DEPLOYMENT_GUIDE.md`。终端入口 `部署助手.bat` 与桌面读取同一 Python 设置，不会猜测并切换成旧电脑环境。检查只在用户主动点击时运行，有超时和防重复控制；不下载权重、不启动模型、不发送视觉 API 请求。

项目 YOLO 的 GitHub 下载地址和 SHA-256 暂留空。后续更新 `requirements/deployment-manifest.json` 中相应模型的 `download_url` 和 `sha256` 即可；不用修改前端。文件已有时可直接选择，不因下载地址为空而阻止配置。

新的模型推荐路径位于 EXE 同级 `models/` 和 `third_party/`。包内路径按相对位置保存，同时保留旧工程布局的查找兼容；外部模型路径换设备后仍需重新选择。新交付默认关闭 Qwen 自动启动，避免尚未配置就尝试加载。

## 已有资料迁移

系统设置 → 用户与工作空间备份：安排备份后关闭并重开，确认 ZIP 生成。目标设备恢复后再重启。恢复会替换当前工作空间而非合并，带回备份中的业务账号；不携带模型权重、Python 环境或云端密钥。

完整备份、恢复和回滚说明在 `docs/桌面版v1.4可靠性与备份说明.md`。不要公开包含账号和现场资料的未加密工作空间备份。

## 验收边界

环境检查验证 Python、依赖可导入性、GPU/CUDA 与文件存在性，不证明 GGUF/mmproj 配对正确、密钥有效、权重许可或实际推理效果。新官方 GPU 环境及另一台实体电脑尚需现场验收，不承诺一键安装所有驱动和模型。
