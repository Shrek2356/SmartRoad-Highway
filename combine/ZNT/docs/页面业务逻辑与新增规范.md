# 页面业务逻辑与新增功能规范

---

## 一、PC 管理端（7 页）

### ① 首页数字驾驶舱 `views/dashboard`

**业务逻辑：** 一屏掌握工地安全态势。顶部队形象横幅（嘉然今天也在守护工地）→ KPI（可点击下钻，待整改/高危/完成率附 yes/emergent/no 表情）→ 左侧平面风险点 → 中间高危视频轮播（成果图占位）→ 右侧图表/排行 → 底部快捷入口。点击点位跳转监控对应摄像头；「演示 AI 检测链路」走通视觉→推理→建单。

**数据：** `api/dashboard.js` · 队形象 `utils/jr.js` / `public/jr/`

### ② 实时视频监控 `views/monitor`

**业务逻辑：** 左侧勾选设备 → 中间 4/9/16 分栏预览 → 画面叠加红/橙/黄掩码 → 右侧点告警定位摄像头。无流地址时显示占位（便于先联调 UI）。

**数据：** `api/monitor.js` · 播放器 `components/VideoPlayer` · 掩码 `components/RiskMask`

### ③ 风险工单处置 `views/workorder`

**业务逻辑：** 筛选列表 → 打开详情（嘉然状态表情、抓拍对比、规范条文、接单/完成/驳回、流转日志）→ 勾选批量导出 CSV。状态机：`pending → processing → done`。表情映射：待处理=`yes.png`，高危紧急=`emergent.png`，已完成=`no.png`。

**数据：** `api/workorder.js` · `utils/jr.js`

### ④ 智能复盘分析 `views/analysis`

**业务逻辑：** 按时间查看隐患趋势、区域热力、班组违规，并导出报告（Mock 提示成功，对接后下载文件）。可跳转「检测结果汇总」查看样例批次细节。

**数据：** `api/analysis.js`

### ④-B 检测结果汇总 `views/detection-results`（新增）

**业务逻辑：** 展示 `FINAL_RESULT_SUMMARY.pdf` 中 7 张施工现场样例的端到端检测结果。布局为：顶部统计（总数/自动确认/人工复核）→ 处理流水线与协同模型 → 总览表（可筛选）→ 分图三联对比（原图 / SAM3 叠加 / 风险掩码）→ 证据门控解释、GLM 边界、优化建议与交付文件。

**数据：** `api/detectionResults.js` · `mock/detectionResults.js` · 图片资源 `public/results/`

### ⑤ 模型规则配置 `views/model-config`

**业务逻辑：** 调检测阈值（影响视觉模型灵敏度）、维护安全知识库、配置分等级推送通道、查看训练进度。仅管理员可见。

**数据：** `api/modelConfig.js`

### ⑥ 安全案例库 `views/case-library`

**业务逻辑：** 检索典型案例 → 一键提交素材生成任务（对接内容生成服务）→ 查看历史归档。

**数据：** `api/caseLibrary.js`

### ⑦ 基础资源管理 `views/resource`

**业务逻辑：** 维护摄像头设备、组织人员树、多项目切换（顶栏同步当前项目）。

**数据：** `api/resource.js`

**业务逻辑：** 面向出入口围观/巡检的极简播报：滚动高危告警、大字展示今日隐患与整改率、循环播案例、展示班组排名。数据每 30 秒刷新。

## 四、新增功能规范（必遵守）

### 分层

```
页面(views/pages) → 接口(api) → Mock 或真实后端
                 ↘ AI(ai) → 模型服务
```

禁止在页面里写死一大段假数据；假数据集中在 `mock/`。

### 新增 PC 页面检查清单

1. `src/mock/index.js` 补充数据  
2. `src/api/新模块.js` 写接口 + JSDoc 入参出参 + `USE_MOCK` 分支  
3. `src/views/新模块/index.vue` 只调 api  
4. `src/router/index.js` 注册路由，`meta.roles` 配权限  
5. 文件头加中文注释：作用 + 后续修改入口  

### 新增移动端页面检查清单

1. `mobile/mock` 补数据  
2. `mobile/api` 补函数  
3. `mobile/pages/xxx` 建页面  
4. `pages.json` 注册（需要则加入 tabBar）  

### 公共能力优先复用

- 视频：`VideoPlayer`  
- 掩码：`RiskMask` / `ai/maskRender`  
- 工单卡片：`WorkOrderCard`  
- 平面/地图：`SiteMap`  

### 命名建议

- 接口文件：业务英文名，如 `workorder.js`  
- 页面目录：与路由 path 一致  
- 风险等级枚举统一：`red` / `orange` / `yellow`  
- 工单状态统一：`pending` / `processing` / `done`
