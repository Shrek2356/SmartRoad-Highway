## 当前 Agent 与“技能”边界

源码清单中没有独立 `SKILL.md` 或 `AGENTS.md`。业务能力主要由 Python 提示词、算子配置和 Agent 类实现；这些才是本次修改对象。用户其他项目的全局施工写作技能没有改动，也不作为本系统运行依赖。

| 能力 | 输入与输出 | 约束 |
|---|---|---|
| 观察 | 原图、道路风险目录 → 可见事实、反证、画面质量、粗略区域 | 不查法规补图像事实，不判断水深、车速、故障或违法 |
| 定位规划 | 已有发现 → 道路主体及具体目标的英文定位短语 | 不新增风险、不改写观察；限制调用数和目标数 |
| SAM3 定位 | 图像与目标短语 → 模型掩码、框和空间关系 | 掩码是预测，不是标注真值；定位失败不能删除可见风险线索 |
| 视觉复核 | 原图、局部图、掩码、原始观察 → 支持、反驳或不确定 | 保留证据冲突；单图不能证明道路安全或事故责任 |
| 法规检索 | 风险类别与描述 → 有出处的候选条款 | 先限定人工整理的条款范围，再按文本相关度排序；未知类别不随机挂条款 |
| 业务处置 | 模型发现 → 复核请求；人工确认 → 工单 | 机器支持不等于人工确认；不自动作出封路、放行或工程验收结论 |
| 复盘与报告 | 原始证据、人工反馈、法规出处 → 问题报告和值班提示 | 反馈不回写原始视觉事实；重复反馈不膨胀样本量 |

道路目录现有 15 项：坑槽、裂缝、沉陷变形、塌方缺口、积水、落石、边坡滑塌堆积物、散落异物、道路阻塞、泥沙覆盖、未细分道路异常、疑似火情、疑似事故或侧翻、交通设施损坏、行人或动物侵入。目录表示检查范围，不表示全部类别已通过效果验证。

## 导入的真实法规

《中华人民共和国道路交通安全法》，2021 年 4 月 29 日第三次修正；原文来自[北京市人民政府门户网站](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202307/t20230710_3158807.html)。网页发布信息列明全国人大常委会和该修正版本。

导入第 25、28、30、32、40、48、52、67、68、70 条，共 10 个条款块，涉及交通设施、道路损毁、道路作业、严重气象或事故下的交通管制、货物遗洒、车辆故障、高速公路特别规定及事故处理。第 30 条网页使用“坑漕”，摘录保留原文，没有擅自改写。

可分发种子资料位于 `detectmodel/Site_Safety_OpenRisk/examples/road_knowledge/`，含原始网页、原文摘录和 `sources.json`。运行时知识库位于 `road_knowledge_base/`，首次初始化导入；之后尊重用户删除或替换。来源校验绑定文件内容，替换后不会沿用旧的“已校验”身份。

报告引用包含条号、版本、官方链接、原文、文件校验值和适用条件。检索分数仅是文本相关度。故障、事故、严重气象等条款都有适用前提，不能由检索命中反向推定违法、事故责任或管制权限。
