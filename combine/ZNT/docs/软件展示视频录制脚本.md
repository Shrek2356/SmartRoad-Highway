# 工地安全智能检测与 Agent 协同平台——软件展示视频录制脚本

## 一、视频定位

- 建议时长：6～8 分钟
- 视频比例：16:9，1920×1080，30 fps
- 展示重点：系统完整性、技术链路、实际操作、结果可解释性
- 核心叙事：从现场图像进入系统，到异常发现、风险定位、规范检索、协同处置和复盘沉淀，形成闭环
- 录制原则：真实界面与真实结果优先；模型等待过程可加速或剪辑，但不要伪造检测结论

## 二、录制前准备

1. 关闭无关窗口、通知和浏览器标签。
2. 设置 Windows 显示缩放为 100% 或 125%，浏览器缩放为 100%。
3. 准备 8 张关键示例图，优先选择：
   - 未佩戴安全帽
   - 人员位于悬吊物下方
   - 临边防护缺失
   - 电缆或临时用电风险
   - 通道堵塞
   - 缺少安全带
   - 人员靠近机械
   - 工人倒地
4. 准备一份可检索的规范文件，建议使用 TXT、MD 或带文本层的 PDF，内容包含“高处作业、安全带、锚点”等条款。
5. 确认初始化模型路径均显示可用。
6. 确认 `5173`、`8810`、`8080` 录制前均未被旧进程占用。
7. 第一次正式录制前完整试跑一次检测，使依赖和显卡内核完成预热。
8. 录屏时保留鼠标指针，开启点击高亮；关闭麦克风环境降噪过强导致的吞字。

## 三、正式录制脚本

### 0:00～0:20　问题引入

**画面**

- 黑场淡入项目标题。
- 快速切换三张施工现场风险图：临边、吊装、未戴安全帽。
- 最后定格平台名称。

**字幕**

> 工地安全智能检测与 Agent 协同平台  
> 开放异常识别 · 像素级定位 · 规范增强推理 · 闭环处置

**解说词**

> 施工现场风险类型复杂，单一检测模型通常只能识别训练集中已有的固定类别。我们的系统将轻量实时感知、视觉大模型开放识别、SAM3 风险定位、RAG 规范检索和多 Agent 协同处置整合为一套完整平台，让异常从被发现到被解释、被处置、被复盘形成闭环。

### 0:20～0:55　一键启动完整系统

**操作**

1. 在资源管理器中双击 `start-platform.bat`。
2. 在启动窗口选择 `2 离线模式`。
3. 展示检测桥健康检查完成。
4. 展示系统自动打开登录页。

**画面字幕**

> 一键启动：检测桥 → 本地 Qwen → Web 前端  
> YOLO / SAM3 / CLIP 按任务加载

**解说词**

> 平台通过统一入口启动。离线模式下，启动器首先拉起本地检测桥，读取初始化配置，并自动启动本地 Qwen 推理服务；检测桥健康检查通过后才会启动前端。YOLO、SAM3 和可选的 CLIP 采用任务级按需加载，避免打开软件时无效占用显存。

**剪辑建议**

- Qwen 首次加载约需几十秒，保留开始和“model loaded”两个关键画面，中间使用 6～10 倍速，并标注“模型首次加载已加速”。

---

### 0:55～1:25　登录动画与系统总览

**操作**

1. 展示嘉然安全员动画完整播放一次。
2. 展示六个模块依次点亮并最终全部变绿。
3. 选择管理员角色并登录。
4. 进入首页数字驾驶舱。

**解说词**

> 登录页面以模块巡检动画展示系统结构。异常检测系统包括实时感知与调度、开放异常识别、风险定位与证据核验；Agent 管理系统包括风险推理、协同处置和复盘学习。六个模块准备完成后进入平台总览。

---

### 1:25～2:05　模型组件与本地部署能力

**操作**

1. 打开“模型规则配置”。
2. 进入“模型部件与运行时”。
3. 展示 Qwen、YOLO、SAM3、CLIP 四个组件状态。
4. 展示模型路径均为“可用”。
5. 展示“Qwen 随平台自动启动”开关。
6. 短暂展示“更新初始化配置”和“恢复初始化配置”，不要实际点击覆盖。

**解说词**

> 平台并未把模型路径硬编码在前端，而是提供模型组件控制台。Qwen 负责开放风险理解和结构化描述；YOLO 负责实时视觉注意力初筛；SAM3 负责实体定位、边界框和像素掩码；CLIP 作为可选语义一致性辅助。所有路径和组件状态都可持久保存，换机部署时只需修改初始化配置。

**强调字幕**

> 模型可替换 · 路径可配置 · 组件可启停 · 本地零 API 成本

---

### 2:05～2:55　RAG 行业规范导入与检索验证

**操作**

1. 切换到“安全知识库管理”。
2. 点击“导入规范文件”。
3. 选择提前准备好的规范文件。
4. 展示导入成功提示和生成的条款块数量。
5. 在检索框输入：“高处作业人员应如何使用安全带和锚点？”
6. 点击“检索验证”。
7. 展示命中的来源文件、条款标题、文本和相关度。

**解说词**

> 管理员可以直接导入企业制度或行业规范。系统支持 MD、TXT、PDF 和 DOCX，导入后自动解析文本，按照标题、章节和条款编号切块，并建立本地检索索引。这里用一个高处作业问题进行验证，可以看到系统返回了具体来源、条款内容和相关度。导入的知识还会参与后续风险推理，而不是只停留在知识库页面。

**注意**

- 不使用纯扫描 PDF；若必须使用，应提前做 OCR。
- 已经导入过同名文件时，可使用另一份演示文件名，避免覆盖提示影响节奏。

---

### 2:55～4:35　完整异常检测链路

**操作**

1. 打开“实时检测”。
2. 展示三种模式：云端、离线、演示。
3. 选择“离线检测”。
4. 选择关键示例“人员位于悬吊物下方”或“工人倒地”。
5. 点击开始检测。
6. 展示流程阶段依次变化：
   - 接收图像
   - YOLO 实时初筛
   - Qwen 开放候选发现
   - SAM3 风险定位
   - 证据核验
   - 二次确认
   - 风险推理与规范映射
   - 处置报告
7. 展示原图、YOLO 初筛图、SAM3 叠加图和掩码。
8. 展示风险名称、置信度、确认状态和人工复核状态。
9. 展示 RAG 规范依据。

**解说词**

> 现在用本地离线链路进行一次完整检测。实时场景下，YOLO 不承担所有复杂异常的最终分类，而是检测人员、机械、防护装备和场景候选，形成视觉注意力区域。视觉大模型随后对完整图像和候选信息进行开放风险理解，输出结构化 RiskSpec。SAM3 根据风险实体和文本提示完成像素级定位，程序化空间关系模块再核验人与机械、悬吊物、临边区域之间的关系。

> 即使某项风险未能形成可靠掩码，只要视觉大模型提供了明确风险描述，系统仍会保留模型判断和不确定性，交由安全人员复核，而不会把“没有掩码”错误等同于“没有风险”。最后，RAG 根据风险名称、可见证据和风险描述检索规范，为推理结果补充可追溯的制度依据。

**剪辑建议**

- 完整推理等待可加速，但至少保留阶段变化的真实画面。
- 在角落标注：“推理等待过程 4× 加速，结果未经修改”。
- 如果现场录制时间不稳定，可先录一次成功结果，再补录开始检测和阶段变化，不要剪接不同图片的结果。

---

### 4:35～5:10　实时监测与全面检测双通道

**操作**

1. 展示“普通帧先经 YOLO 初筛”的说明。
2. 展示 30 分钟、2 小时全面检测设置。
3. 点击或指向“立即全面检测”。
4. 展示其“绕过 YOLO 候选限制，检查完整图像”的提示。

**解说词**

> 系统为生产监控保留了双通道。普通视频帧先由轻量模型持续初筛，只把高价值候选送入大模型；同时可以每 30 分钟或 2 小时执行一次完整图像审计，也可以由安全员立即触发。这样既控制计算成本，又避免实时模型训练类别有限而长期漏掉开放异常。

---

### 5:10～6:10　Agent 协同处置闭环

**操作**

1. 打开“检测结果汇总”，展示刚才结果已自动同步。
2. 打开风险详情或对应结果卡片。
3. 进入“风险工单处置”。
4. 展示风险等级、规范依据、责任人、处置状态。
5. 切换一次工单状态或展示审批/复核入口。
6. 打开“智能复盘分析”。
7. 展示统计趋势、案例沉淀或复盘入口。

**解说词**

> 检测完成后，结果会进入统一结果库。风险推理 Agent 根据检测置信度、证据状态和规范依据完成风险定级；协同处置 Agent 将风险转为可跟踪的工单和复核任务；复盘学习 Agent 汇总历史事件、处置过程和人工反馈，为后续规则调整、数据标注和模型迭代提供材料。

> 当前演示版重点验证的是检测结果向工单、复核和复盘模块的数据传递结构。真实生产部署时，可继续对接企业账号、消息通知和工单系统。

**真实性提示**

- 如果该页面仍使用演示数据，应在字幕中写“Agent 交互界面与数据结构演示”，不要宣称已接入真实企业工单平台。
- RAG 上传、检索以及检测桥异常检测链路可以明确标注为真实本地执行。

### 6:10～6:45　八个关键示例结果快览

**画面**

- 使用 2×4 宫格或快速轮播展示八个示例。
- 每张展示：原图、异常名称、掩码/叠加图或“仅报告识别”、置信度。
- 每张停留 2～3 秒。

**解说词**

> 除了本次现场演示，系统还对八类关键场景进行了组合链路测试，覆盖个人防护、吊装、临边、机械距离、电气风险、通道管理和人员倒地等异常。系统既支持已知风险的结构化核验，也保留开放风险发现和人工复核出口。

        ↓

## 四、推荐录制顺序

为避免模型等待或操作失误，实际录制可以不按成片顺序：

1. 先录完整检测过程和最终结果。
2. 再录 RAG 导入与检索。
3. 录模型配置页面。
4. 录结果、工单和复盘页面。
5. 最后关闭全部后台，再录一键启动和登录动画。
6. 剪辑时按正式脚本顺序重新排列。

## 五、旁白与字幕规范

- 旁白语速：每分钟约 220～260 个汉字。
- 模型名称首次出现写全称，后续使用简称。
- 不使用“百分之百准确”“完全替代安全员”等绝对表述。
- 区分三个状态：
  - 已确认：证据链通过。
  - 待复核：模型发现风险，但定位或关系证据不足。
  - 未确认：当前图像证据不足，不代表现场一定安全。
- 加速片段必须标注倍速。
- 真实本地运行可以标注“本地模型、无云端 API 调用”。
- Agent 页面若仍含 Mock 数据，应明确标注为界面与流程演示。

## 六、30 秒精简版备用文案

> 面对工地训练类别有限、复杂关系风险难识别的问题，我们构建了轻量实时感知、视觉大模型开放识别、SAM3像素定位、RAG规范检索与多Agent处置协同的一体化平台。YOLO负责低成本初筛，Qwen输出结构化风险描述，SAM3和空间关系模块提供可视证据，RAG把企业规范引入风险推理，最终形成检测、复核、派单和复盘闭环。系统支持本地离线部署，模型与路径均可替换配置。
