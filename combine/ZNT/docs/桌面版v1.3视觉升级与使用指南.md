# 筑安智巡 · SiteSafe-Sentinel 1.3.0

本版统一桌面平台的视觉系统：明亮模式采用雾白底色，深色模式采用石墨蓝底色；青绿色用于操作和选中，红／橙／黄用于风险提示。保留嘉然动画、全部八个预置案例、原图、检测框、掩码与报告，不改检测策略，不增加模型调用。

本文的“直接打开”面向完整桌面交付包。**GitHub 的源码 ZIP 不是完整运行包**：源码开发者需先构建前端和 EXE，并安装业务依赖，步骤见[桌面开发说明](../desktop/README.md)。验证范围、包文件名及校验值见[v1.3 记录](./v1.3视觉验收记录.md)。

## 直接打开

完整解压文件夹，双击根目录 `SiteSafe-Sentinel.exe`。不要只复制 EXE。Windows 10/11 64 位需要 Microsoft Edge WebView2 Runtime；演示所需 Python 和已编译前端已随包提供，无需系统 Node、GPU 或模型权重。演示案例不能当作现场实时事件。

如果旧版仍在运行，请先关闭旧版窗口，再打开新版，避免端口冲突。旧版本文件不会被本包删除。默认账号：管理员 `admin / admin123`、安全员 `safety / safety123`、总监 `viewer / viewer123`；正式使用应更改默认凭据。

## 如何体验新版

1. 登录：嘉然六模块动画保留，在 5.5 秒附近停帧；绿色表示功能导览完成，不代表模型已经运行。
2. 首页工作台：项目选择、真实服务状态、指标和证据入口集中展示；地图点位与指标支持键盘访问。
3. 右上角灯光按钮：即时切换明暗主题，偏好保存在当前设备。
4. 用户菜单 → 展示视图：查看保留的嘉然主题横幅。展示视图与“预置素材”开关互相独立。
5. 检测结果汇总：查看八个案例，点图查看定位与证据；展示案例始终带来源标记。
6. 实时检测：青绿描边表示选中的检测模式，黄褐提示表示仍需配置；不会把连接失败自动变成 Mock 结果。
7. 使用与支持：操作路径、功能搜索、连接诊断与常见问题。也可按 `Ctrl + K` 搜索具体功能。

## 真实检测与新设备配置

模型权重不包含在本包内。请先阅读[环境与依赖说明](../requirements/README.md)和部署助手，在“系统设置 → 桌面与连接”选择完整 Python 环境；在“模型规则配置 → 模型部件与运行时”选择推理引擎、Qwen、YOLO、SAM3 和可选 CLIP 路径。云端使用另行配置 API 地址与密钥。检测桥在线不等于模型已加载；配置通过也不等于推理验收通过。

原有实时初筛、定期全图检查、直接图片检测、风险工单、Agent、RAG 规范导入和人工复核入口保留。详细功能使用与限制继续参见 [v1.2 使用指南](./桌面版v1.2产品体验与使用指南.md)（包根目录阅读时请在 `docs/` 查找该文件）。

## 视觉实现与维护

- `pc-admin/src/utils/designTokens.js`：两套语义色、组件和图表颜色的统一来源；不再为每页各写一套主题色。
- `pc-admin/src/styles/global.css`：基础排版与语义状态；`product.css`：通用工作界面。
- 浅色侧栏降低视觉压迫，深色侧栏与内容保持层级；小高度窗口采用紧凑菜单。
- 风险标签、趋势图、地图、表格、滑杆、按钮、弹层和登录表单共同适配明暗主题。导出海报采用固定、适合阅读的配色，不跟随夜间背景。
- 清除旧版全局样式对危险／禁用按钮和进度条的强制覆盖；保留焦点描边与减少动效偏好。

本次验证覆盖核心色板对比度与前端回归，不等于完整 WCAG 认证或生产验收。没有重新跑大模型，没有改变已有异常检测结果。界面中真实数据、演示素材、未知状态仍需分别理解。
