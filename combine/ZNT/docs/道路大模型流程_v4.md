# 道路大模型流程 v4：实现与验证

2026-09-13。更新限于服务器道路分析；未训练摄像头端实时模型。

## 已实施

1. **观察与定位规划拆分**：首轮只输出场景可见性、质量限制、具体事实、反证及粗区域，不再要求自报置信度。第二次模型调用只能为已有risk_id规划具体定位目标。程序冻结观察，防止规划改写事实。
2. **定位触发修正**：有具体可见事实并得到定位计划就执行SAM3，不以置信度0阻断。模型未给计划或规划失败时仍保留观察，并使用原图复核。
3. **有界计划修复**：遗漏或结构错误最多修复一次；未知风险编号拒绝。一个风险类别允许多个具体物体，目标去重后最多两个，最多规划8类风险，SAM3总任务上限24。超出预算写入限制，不宣称已检查全部目标。
4. **独立画面状态**：adequate、limited、unassessable及具体原因独立保存。只有无数据或遮挡、没有可见异常事实时，进入无法判断，不创建塌方风险。
5. **独立复核**：即使SAM3没有掩码，也核对原始观察。有依据的粗区域允许附加一张局部复查图，明确它不是精确掩码。复核分别输出视觉判断及定位一致性，保留反证。未通过几何或视觉检查仍待复核。
6. **自动报告**：每次生成issue_report.md与issue_report.json，包含事实、反证、未决事项、定位状态、建议补充信息、输入哈希、提示与原始输出链接及版本信息。现场时间与道路位置未提供时保持未知，不编造封路、通行或工程结论。
7. **软件呈现与入库**：assessment_quality从检测结果传至业务事件；页面区分待复核、无法判断、未发现可见异常，提供报告入口。不再把无确认结果显示成绿色成功结论。

实现文件：site_safety/pipeline/road_workflow.py、road_evidence.py、road_report.py及对应调用、Schema和前端。offline和standard启用v4，demo仍为模拟联调。

## 尚未实现或验证

- 图像质量由大模型判断，尚无独立校准过的质量模型；模型仍可能遗漏可见异常或误判无数据范围。
- 当前几何算法仍以保守空间关系为基础；道路缺口和完全淹水的专项几何判定、固定摄像头道路区域标定尚未完成。
- 局部复查是原图辅助视图，不是重新训练模型或无限重试分割。尚未实现跨帧跟踪、事件去重与定时日报。
