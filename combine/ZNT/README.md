# 路安智巡 · 道路风险检测实验室原型

本仓库用于高速公路图像风险检测的小试验证。当前采用道路图像观察、定位任务规划、SAM3定位、视觉复核、人工业务复核与报告留存的流程。

## 启动与配置

- 已构建源码：运行 `start-platform.bat`，启动 `desktop-dist/SmartRoad-Inspection.exe`。
- 演示、本地、云端配置分别为 `configs/road_demo.yaml`、`road_offline.yaml`、`road_standard.yaml`，均位于 `detectmodel/Site_Safety_OpenRisk`。
- 演示模式只做模拟联调；真实检测选择本地模式，配置 Qwen、视觉投影、llama.cpp 与 SAM3。道路端侧模型尚未训练，旧工地 YOLO 权重不参与道路筛选。
- 本地开发模型路径由运行时设置保存；可移植软件包需要在新设备重新选择实际路径。

## 法规与报告

道路知识库首次初始化会导入《中华人民共和国道路交通安全法》2021 年第三次修正版的 10 条相关条文，来源为北京市政府门户网站。出处、版本、适用条件和校验值保存在 `examples/road_knowledge/sources.json`。用户删除或替换法规后，系统不会静默恢复或沿用失效的来源校验。

检测结果生成问题报告、原图观察、掩码和复核记录。法规是条件性的处置参考，不能代替视觉证据，也不构成违法认定。机器支持与人工确认分别记录。

## 开发与验证

详见 [道路领域全面迁移检查](docs/道路领域全面迁移检查_20260921.md)。历史工地配置、测试和交付记录保留用于追溯；产品入口拒绝加载工地配置。`site_safety` 与 `Site_Safety_OpenRisk` 为兼容代码路径名。

现有公开数据与合成样例用于开发验证，不能据此宣称全场景准确率或无漏检。实时视频的时间关联、标定与端侧模型需在后续试点中单独验证。
