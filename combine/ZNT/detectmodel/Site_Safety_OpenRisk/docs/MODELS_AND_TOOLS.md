# 模型与工具清单

| 环节 | 模型或工具 | 实际职责 | 是否随包提供权重 |
|---|---|---|---|
| 实时初筛 | YOLO26 | 人员、PPE、机械、车辆与疑似区域检测，只负责路由 | 否 |
| 开放风险识别 | Qwen3-VL或兼容MLLM | 场景理解、开放风险发现、RiskSpec和风险报告 | 否 |
| 风险定位 | SAM3 | 文本概念定位、Bounding Box、Pixel Mask和Presence Score | 否 |
| 可选语义辅助 | CLIP ViT-L/14 | ROI或Mask与风险文本的一致性辅助，默认关闭 | 否 |
| 服务接口 | FastAPI | 业务API、检测桥、RAG导入与健康检查 | 源码提供 |
| 前端 | Vue、Vite | PC管理端、大屏和移动端 | 源码与依赖提供 |
| Agent | 本地确定性逻辑与MLLM能力 | 风险推理、协同处置、规范检索、复盘学习 | 源码提供 |

所有外部模型路径均通过设置页或部署助手配置，代码不依赖固定个人目录。
