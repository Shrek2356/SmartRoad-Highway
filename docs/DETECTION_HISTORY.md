# 检测历史与原图归档

2026-09-22，已纳入 1.4.5 正式安装包；此前作为 1.4.4 本地功能补丁验证。

检测任务中心现在显示原图缩略图，可展开标注图，点击“过程与结果”查看原图、道路场景标注、多风险叠加图、掩码和逐图报告。正常场景也作为独立历史记录保存。

已完成任务可点击“归档留存”。归档记录不参与按天数和缓存容量执行的自动清理，并包含在桌面工作空间备份中。普通未归档任务仍按原缓存策略管理。

外部批量测试可以通过“导入检测档案”上传 ZIP。档案需要 `detection-archive.json` 清单及 `samples/<样本编号>/` 下的原始文件，格式为 `smartroad-detection-archive-v1`。HTML、PDF 和原来的报告附件 ZIP 不是这个导入格式；本批提供单独的“道路检测v5_15图_可导入历史档案.zip”。开发者可用 `site_safety.detection_archive.build_archive` 将包含 `detection_event.json`、`visual_verification.json`、`result.json` 和原图的输出目录打包。

导入逐文件校验大小与 SHA-256，先验证整个档案，再发布完整任务目录；重复导入同一批不会生成重复记录。原图、掩码、模型原始文本、提示词及报告文件按原字节保存，服务展示使用重新定位到软件目录内的图像路径。检测时间与导入时间分别记录。

历史导入独立保存在检测档案中，不进入现场告警、工单、待确认业务队列或实时统计。打开档案不重新调用模型，也不把预测改写成人工确认。归档不是训练或自动知识学习。

本次 15 图为开发验证：10 张合成高速场景和 5 张 UA-DETRAC 正常候选图，沿用原有未确认状态。测试图片不能冒充当前现场事件。
