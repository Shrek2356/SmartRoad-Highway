# 字号与画面放大

2026-09-22 · 路安智巡 SmartRoad-Highway 1.4.5 前端更新

## 调整日常字号

进入 **系统设置 → 工作台与展示 → 字体大小**，可从 100% 调到 200%，每步 5%。预设为标准 100%、大 125%、特大 150%、最大 200%。建议先试 125% 或 150%。修改立即生效，并在当前浏览器或桌面窗口的用户配置中自动保存。

右下角 **字号** 提供相同的快捷设置，登录页和各角色均可使用，不要求管理员权限。字号增大时，菜单和文字允许换行；图片、视频及检测数据不变。

![150% 字号设置](images/reading-font-150.png)

## 保持布局，整体放大

点击右下角 **放大查看**，然后把鼠标移到要观察的区域，滚动滚轮即可缩放；也可直接使用 **Ctrl＋滚轮**。画面支持 100%–400% 放大，围绕鼠标位置缩放。按住鼠标左键拖动，可以查看画面其他部分。

查看模式只用于观察，页面按钮暂时不可操作，避免平移时误触。按 **Esc** 或 **退出查看** 返回原画面并恢复操作。工具条的加减按钮，以及 **Ctrl＋加号／减号**、**Ctrl＋0** 也可使用。

普通模式仍用滚轮翻页，三维模型内部仍按原有方式缩放模型。需要查看尚未滚到的内容时，退出查看、滚动到该位置，再放大。画面放大不改变排版宽度、字体设置或图片坐标，不会生成原图不存在的新细节。

![监控图片整体放大](images/reading-monitor-zoom.png)

## 验证记录

- 前端测试 42 项通过，生产构建通过。构建仍提示部分资源块较大。
- 实际浏览器操作验证 100%、125%、150%、200% 字号；125% 在页面重新加载及重新登录后保留。
- 滚轮放大至约 143% 时，文字示例的布局宽度保持 848 px、高度保持 57 px、字号保持 16 px；可视宽度由 850 px 变为约 1218 px。平移后按 Esc 恢复原尺寸。
- 监控示例图的布局宽度保持 439 px，可视宽度放大到约 629 px；原图 1024 px，正常加载、无灰度滤镜。摄像头名称双击仍跳转到对应图片。
- 指南抽屉随画面放大，Esc 只退出查看模式，之后仍可正常关闭抽屉；普通滚轮不会触发全局放大。Ctrl＋加号键盘入口已实测。
- 明亮模式继续使用黑白水墨配色，黄红警示色沿用既有规则。

本次是界面可读性更新，未重新运行检测模型，也未重建完整安装器。本机更新只替换前端资源，已核对历史档案及配置文件保持原字节。测试使用限时运行的本地服务，服务自动停止或重启时出现的离线／会话过期提示不属于检测结论。

## 实现说明

字号设置分别驱动源码样式、Ant Design 组件和图表文字；构建时只转换字号与行高，不缩放布局尺寸。独立查看模式通过顶层视图变换完成，弹窗在同一视图内，控制条置于视图外，保证放大后仍可退出。切换页面会退出查看模式，字号设置则保留。
