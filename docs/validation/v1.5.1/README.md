# 路安智巡 v1.5.1 路面掩码分层显示

在实时检测结果或历史任务详情的“场景与风险标注”中使用：

- 正常路面显示绿色半透明掩码和绿色框，表示本次未见可见异常。
- 蓝色标注场景对象；黄／红色标注异常候选／已确认异常。
- 可选择仅框、仅掩码、框与掩码，调节透明度，逐项显示或隐藏。
- 护栏图层默认隐藏，可手动开启。
- 历史档案读取已保存的真实掩码，不重跑模型、不改写原结论；缺失或尺寸不匹配的掩码不会伪造填充。
