# 路安智巡 1.4.5 更新与验证

日期：2026-09-22；阶段：实验室小试。Windows 安装包已构建，并通过真实安装器将本机从 1.4.4 升级到 1.4.5。

## 更新内容

- 历史档案保留原图、场景标注、各风险掩码和逐图报告，正常场景也完整保留。
- 检测任务中心显示原图缩略图，支持“只看已归档”“归档留存”和专用 ZIP 导入。已归档数据不参与缓存自动清理，重复导入不会生成重复记录。
- 历史导入沿用原检测时间与复核状态，不触发现场工单、通知或自动训练。
- 修复 Windows 关闭长路径支持时恢复临时文件名过长的问题；恢复归档时保留原始证据字节和来源，只调整服务展示路径。

## 查看与迁移

本机 15 张开发测试结果已经在软件中，不必重新导入。打开“检测任务中心 → 只看已归档 → 过程与结果”。现有 1,405 个原始证据文件经升级前后校验完整保留。

新电脑先安装 1.4.5，再导入附件 `road-v5-history-15-20260922.zip`。普通 HTML 或以前的分析附件 ZIP 不属于软件导入格式。基础安装包不包含模型权重、私人配置或业务数据库。
