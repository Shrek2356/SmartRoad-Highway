# 路安智巡 v1.4.6 安装包与验证

本版将最新界面功能正式纳入 Windows x64 安装包，供下载安装使用。项目仍处于实验室小试阶段。

## 新功能

- 乐西高速三维示意工作台：旋转、缩放、平移、大图、设备和路况点位联动；路线与事件为标明来源的虚构演示。
- 深蓝工业主题和黑白水墨明亮主题；黄红警示保留，照片及证据保持原色。
- 双击首页摄像头名称进入对应监控示例，包含 5 张固定匹配的正常道路图片及来源记录，支持单画面和多分栏。静态图片不是现场实时视频。
- 字号 100%–200%，即时生效并自动保存；右下角提供快捷入口。
- 画面整体放大 100%–400%，保持原布局，支持滚轮、拖动和 Esc 退出；查看模式暂时锁定页面操作。
- 修复旧打包脚本遗漏道路监控图片的问题，同时携带字体构建脚本和带截图的使用说明。

## 安装和升级

下载 `SmartRoad-Inspection_Setup_v1.4.6_x64.exe` 并按向导安装。已有道路安装版先正常关闭软件，建议做好备份，选择原软件安装目录进行升级。安装程序保留个人配置、业务库、知识库及历史档案。

新设备安装后可以直接浏览演示界面。真实检测需要另外配置模型和检测环境；基础安装包不包含 Qwen/SAM3 权重和 GPU 环境。已有历史档案可以继续使用，新电脑可导入附件 `road-v5-history-15-20260922.zip`，无需重新运行模型。
