# 路安智巡 v1.5.0 · 持续改进与回归

已接通“纠错与补标 → 人工审核 → 候选案例经验 → 真实模型配对回放 → 启用或回退”。默认不含已批准经验，尚未开展本版真实模型精度对照或 LoRA 微调。

## 使用入口

在实时检测、历史任务或真实结果卡片中点击“纠错与补标”；在“Agent协同学习 → 持续改进与回归”审核样本和管理版本。[带截图的详细说明](../../CONTINUOUS_LEARNING.md)。

- 支持误报、漏检、类别错误、定位错误、新类别候选及正常抽查。一张图可添加多个类别，框为范围标注。
- 保存原图、人工判断、原始模型结论与审核记录；不修改原始检测证据。
- 审核通过的训练案例才能生成候选经验。验证和保留测试数据禁止检索；同图哈希和来源分组禁止跨用途。
- Qwen 先观察当前图，再检索最多两个相关人工案例辅助视觉复查；提示词区分当前图与参考图。SAM3 定位与证据核验继续执行。
- 配对回放分别运行当前版和候选版，比较最终 verified 风险的误报／漏报、保留观察的漏项和人工范围框 IoU。它们是按图像类别统计，范围框 IoU 不是像素掩码精度。
- 回放使用真实标准／离线模型，禁止 Mock，不生成现场告警、工单和通知。可打开两个版本各自的图像与报告，并下载对照报告。
- 候选版需通过至少4张整图复核、2个独立分组、正常与相关风险正例及范围框覆盖的门槛；需有改善且未发现逐图退步。管理员启用前重新校验数据和配置，可回退原始流程。
- 新类别保留 open_ 候选，正式风险目录不自动扩充。原图与人工标注可按用途分别导出，用于后续训练准备。
