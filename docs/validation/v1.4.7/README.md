# 路安智巡 v1.4.7 · 图像规范参考记录

本版在检测结果中加入独立的规范参考窗口，将原图、场景标注与当时保存的规范摘录并排展示。项目仍为实验室小试原型。

## 功能与使用

- 在实时检测结果点击“规范参考记录”；在历史档案或已关联真实任务的结果卡片点击“规范参考”。
- 同图多异常按标签分别展示，包含规范名称、条款原文、版本、适用条件、来源网页及文本相关度。
- 展开“来源与留痕”查看引用编号、摘录块、资料采集时间和 SHA-256；可以打开原始 JSON 记录。
- 新检测记录实际检索词、检索时间、限定条款范围和匹配状态，自动问题报告同步记录。
- 历史档案读取原快照，不重新检索、不补造缺失字段。正常、无匹配、未配置、未保存和读取失败分别提示。
- 深蓝和水墨主题、字号调整及画面放大继续可用。

[带截图的使用说明](../../RAG_REFERENCE_RECORDS.md)。引用条款供人工核查处置条件，不替代视觉证据、现场核验或违法认定；文本相关度不是检测置信度。

## 安装与升级

Windows x64 下载 `SmartRoad-Inspection_Setup_v1.4.7_x64.exe`。先正常关闭软件，再选择原目录升级。个人配置、业务库、知识库和检测档案保留。新设备可导入附件 `road-v5-history-15-20260922.zip`。

基础包含服务运行时，真实检测所需大模型权重和 GPU 环境仍需单独配置。本次未重跑真实 Qwen/SAM3，不产生新的检测准确率结论。
